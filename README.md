# Weixuan Ding — Academic Website

Personal academic website built with Astro.

## Update content

- About me: `src/content/profile/about.md`
- News: add a Markdown file in `src/content/news/`
- Publications: add a Markdown file in `src/content/publications/` (use `presto.md` as the template)
- Profile photo: replace `public/images/profile.png`
- CV: replace `public/files/CV.pdf`

## Build

```bash
pnpm build
```
